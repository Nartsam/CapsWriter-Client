# 识别语言如何配置

## 作用

告诉服务端这段语音是什么语言。识别由独立部署的 CapsWriter-Server（Qwen3-ASR）完成，客户端只把这个设置随音频一起发过去。

---

## 配置方法

打开项目根目录的 `config_client.py`，找到：

```python
language = 'auto'
```

改完重启客户端生效。取值**不区分大小写**（如 `Chinese`、`CHINESE` 均可）：

| 值 | 说明 |
|----|------|
| `auto` | 不指定语言，由模型自动判断 |
| `chinese` | 中文 |
| `english` | 英文 |
| `cantonese` | 粤语 |
| `japanese` | 日文 |
| `korean` | 韩文 |
| 其他 | 见下方完整列表 |

Qwen3-ASR 支持的全部取值：`chinese`、`english`、`cantonese`、`japanese`、`korean`、`arabic`、`german`、`french`、`spanish`、`portuguese`、`indonesian`、`italian`、`russian`、`thai`、`vietnamese`、`turkish`、`hindi`、`malay`、`dutch`、`swedish`、`danish`、`finnish`、`polish`、`czech`、`filipino`、`persian`、`greek`、`romanian`、`hungarian`、`macedonian`。

写了不在列表里的值时，服务端按 `auto` 处理。取值的对照表在服务端仓库的 `core/server/engines/language.py`。
