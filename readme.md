# CapsWriter-Client

> **按住快捷键说话，松开就上屏。**

CapsWriter 离线语音输入的**客户端**（Windows）：按住快捷键录音，把音频发给 **CapsWriter-Server** 服务端识别，拿到文字后做热词替换、可选的 LLM 处理，再模拟键盘输入到当前窗口。服务端是另一个仓库（与本仓库同级的 `CapsWriter-Server`），部署、模型与显卡加速看那边的说明。

Fork 自 [HaujetZhao/CapsWriter-Offline](https://github.com/HaujetZhao/CapsWriter-Offline)，只维护客户端，仅供个人使用。

## ✨ 核心特性

-   **语音输入**：按住快捷键（默认右 Ctrl，可配鼠标侧键）说话，松开即输入，默认去除短句末尾的逗句号。支持长按和单击两种录音模式。录音时输入光标旁有悬浮提示；按 `Esc` 可作废这次录音。
-   **文件转录**：音视频文件往 `start_client.exe` 上一丢，字幕 (`.srt`)、文本 (`.txt`)、时间戳 (`.json`) 统统都有。
-   **热词替换**：在 `hot.txt` 记下偏僻词，通过音素模糊匹配，相似度大于阈值则强制替换。
-   **正则替换**：在 `hot-rule.txt` 用正则规则精准强制替换。
-   **LLM 角色**：识别结果的开头匹配角色名时交给该角色处理（润色、翻译、问答）；支持读取选中文字、联网搜索、截图提问、连续对话、一次性提醒，可在 OpenMate 桌面看板上展示。
-   **托盘菜单**：右键托盘图标可复制结果、编辑上下文、打开热词文件、清除 LLM 记忆、重开音频、重启。
-   **日记归档与录音保存**：按日期保存每一句语音的识别结果（`年/月/日.md`）和录音文件（`年/月/assets/`）。

数字 ITN（「十五六个」→「15~16个」）、中英文空格等格式化由服务端完成。

## 💻 平台支持

目前仅能保证在 **Windows 10/11 (64位)** 下正常运行。


## 🎬 快速开始

1.  **准备服务端**：按 CapsWriter-Server 的说明启动服务端（本机或另一台机器）。
2.  **准备环境**：确保安装了 [VC++ 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)。若要使用文件转录功能，还需安装 [FFmpeg](docs/环境依赖安装说明.md)。
3.  **填写服务端地址**：在 `config_client.py` 里设置 `addr`（可写成多个候选地址的列表，按顺序尝试，首个连上的会被锁定）和 `port`。
4.  **启动听写**：双击 `start_client.exe`，**它会自动最小化到托盘菜单**，连上服务端后控制台显示绿色的「已连接服务端」。
5.  **开始录音**：按住录音快捷键就可以说话了！


## ⚙️ 个性化配置

客户端的设置都在根目录的 `config_client.py`（改完重启客户端生效）；LLM 角色在 `LLM/` 目录下，每个 `.py` 文件是一个角色（改完自动生效）。


## 🛠️ 常见问题

**Q: 为什么按了没反应？**
A: 请确认 `start_client.exe` 的黑窗口还在运行，并且已连上服务端。若想在管理员权限运行的程序中输入，也需以管理员权限运行客户端。

**Q: 为什么识别结果没字？**
A: 到 `年/月/assets` 文件夹中检查录音文件，看是不是没有录到音；听听录音效果，是不是麦克风太差，建议使用桌面 USB 麦克风；检查麦克风权限。

**Q: 想要隐藏黑窗口？**
A: 点击托盘菜单即可隐藏黑窗口。

**Q: 如何开机启动？**
A: `Win+R` 输入 `shell:startup` 打开启动文件夹，将客户端的快捷方式放进去即可（服务端的开机启动见服务端说明）。

更多问题请参阅 [docs/常见问题.md](docs/常见问题.md)。
